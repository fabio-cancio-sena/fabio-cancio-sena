# Hi, I'm Fábio 👋

**Senior Machine Learning Engineer @ Nubank** — ML Platform · Decision Systems · Model Observability & Governance · Agentic / AI-Native Engineering

> I build the platforms that make automated decisions reliable — and their actions accountable.

I work on a specific class of problems: when an automated decision fails in production, how do you understand *why*, contain the blast radius, and resolve it fast? At Nubank I architect and build the decision-monitoring and governance platforms that track millions of production decisions across credit and risk — incremental, lineage-aware pipelines over distributed, event-driven architectures, built from the start for audit (SOX, Model Risk), explainability, and policy enforcement.

Most ML systems are built to *predict*. I build the layer that makes those systems **reliable** — and their actions **accountable**.

### 🛠️ What I work on

- **ML & decision platforms** — monitoring, governance, and observability for production ML and automated decisions
- **Distributed data systems** — incremental, lineage-aware pipelines; backfills and late-arriving data; idempotent, long-lived data assets
- **Agentic infrastructure** — LLM-powered, tool-using agents (MCP) wired into on-call to run first-response incident analysis
- **AI-native engineering** — redesigning internal platforms so codebases *rhyme* with the pre-trained intuitions of modern LLMs

### 🔭 Currently

- Co-designing **Caramelo**, Nubank's next-gen monitoring platform for models and policies (Scala · Spark), replacing a legacy system across a **500+ job estate**
- Building agent-based on-call debugging tooling that cuts time-to-diagnosis for production ML incidents
- Exploring **Agent Experience (AX)** as an information-architecture problem for AI-native platforms
